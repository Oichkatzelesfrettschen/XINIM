Compiler Driver
===============

The XINIM build includes a dedicated compiler front-end implemented by the
``CompilerDriver`` class. It is compiled as the ``minix_cmd_cc`` target.

.. warning::

   `commands/cc.cpp` is now archived to :file:`archive/legacy/commands/cc.cpp`
   as a reference command implementation, so no active doxygen reference is
   maintained for this lane.
